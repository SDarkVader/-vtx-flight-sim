# Operator-provided landing account

The five JPEGs in this directory depict the same run. The aircraft drifted toward the water while losing altitude, the connection dropped, and the operator took manual control and landed it. The images are preserved as supplied; phone timestamps alone are not evidence of separate runs.

The archived live session `20261031T114125-81987f` records authority changing from Colin to manual. Its last sensor sample (observation 1043) shows approximately level attitude, near-zero velocity and compression on all six feet. Its original summary says the session ended on server shutdown; that original outcome has not been rewritten to claim mission completion.

The operator subsequently advised checking descent immediately, leveling and regaining height, aiming for 8–10 m clearance, using the individual fan vectors and counter-thrust, and avoiding allowing clearance to fall below approximately 4–5 m during forward motion. These are pilot instructions and simulator experience, not validated aircraft performance or safe operating limits.
